# 树高仪 R4：以原成功测距工程为基线

日期：2026-11-14。依据用户再次确认：`GTI-test-KeyMeasure` 的激光从未出现问题。本版从该工程重新复制，只在主程序增加树高流程；不沿用树高R3的激光驱动改动。

## 本次具体保留了什么

以下文件已与桌面“课设/GTI-test-KeyMeasure”逐文件哈希比较，一致：

- laser_control.c：原始按键消抖、按下触发测距、START/STOP时序、CRC顺序回退、4秒等待与停止确认。
- laser_uart.c、laser_protocol.c、laser.h：原串口初始化、命令发送、接收和帧解析。
- oled.c、oled_port.c、mpu6050.c、mpu_bus.c：原显示、I²C与测角驱动。
- GTI-test.uvprojx：原Keil工程配置。

RTE时钟和启动文件也从同一基线复制。主循环保留原处理顺序：laser_poll → laser_control_poll → 原key_input → MPU采样/重连 → 新增应用状态更新 → OLED显示。没有OLED分页回调，没有树高R3的500ms启动准备、6秒等待、TC等待或通信诊断改动。恢复基线行为不等于已确定此前故障原因。

在测距步骤，真实KEY1电平直接交给原key_input；顶/底角保存阶段不给它传入按下电平，以免保存角度时误启动激光。主程序不直接调用laser_command，不改原激光状态机。校零长按松开前不会自动触发测距。

## 已取消的拦截

没有KEEP STILL连续稳定窗口，没有陀螺仪门限，没有加速度幅值门限，也没有侧倾门限。测距请求不会因这些检查被拒绝，得到的距离也不会因微小晃动被软件丢弃。保留传感器读取状态、角度新鲜度、计算角度范围、原有效距离和原停止确认。

操作者仍需保持瞄准方向与位置，取消稳定门限不消除晃动造成的误差。激光与6050必须保持相对固定；暂时可以固定在电脑旁，只验证距离恢复，不必先完成手持外壳或购买供电线。

## 先烧录，再只验证测距

1. 解压到新文件夹，打开本版GTI-test.uvprojx；不要覆盖原成功工程，不要误开R1/R2/R3工程。
2. Rebuild，确认0错误、新HEX已生成。包内不附旧HEX/AXF。
3. 全部断电，取下底板JP1、拔下底板J5；按原成功方式接DAP及核心板单路供电，点击Download，确认Programming Done、Verify OK。
4. 下载完成后全部断电，拔DAP及电脑供电线，恢复JP1/J5与已核对的正常供电。蓝色转接板若由J8供电，不同时插电脑USB；核心板亮灯不能证明激光供电正常。
5. 上电时短暂显示TREE HEIGHT R4，随后0 LEVEL LASER R4。激光与6050一起放稳、激光轴调水平，长按KEY1约2秒，然后完全松开。
6. 出现1 KEY1 RANGE。瞄准约1m哑光墙面，短按KEY1；测距仍按原工程在按下消抖后启动，不需要松手等待稳定测试。
7. 先只看激光是否工作、是否出现HOLD距离并进入2 TOP KEY1 SAVE。成功后反馈一次，再继续测顶/底；不要先把“进入计算页面”当高度精度通过。

如果仍无光/超时，下一步是在完全相同供电和接线下回烧原GTI-test-KeyMeasure复测。只有旧版在当前硬件条件下也复现或仍正常，才能更有把握地区分接线/供电变化和新增主程序影响。不要把之前成功自动当成本次电压、线束与接触也都已验收。

## 测高步骤

| 屏幕 | 操作 |
|---|---|
| 0 LEVEL LASER R4 | 激光轴真实水平，长按KEY1约2秒，松开 |
| 1 KEY1 RANGE | 瞄准树干或墙面，短按；原激光按键函数启动一轮测距 |
| HOLD距离、2 TOP KEY1 SAVE | 瞄准树顶/上标记点，短按松开KEY1保存顶角 |
| 3 BASE KEY1 SAVE | 瞄准树底/下标记点，短按松开KEY1保存底角 |
| HEIGHT/HORIZ/HOLD | 树高、水平距离和原激光斜距；短按松开回第1步，下一次短按再测距 |

在第2/3步或结果页长按约2秒，回第0步重新校零。第1步长按仍会像原测距工程一样先启动一次测距，不用于校零；需要重新校零时可RESET后重做。忙碌时不补执行按键。顶/底角按松开保存，长按不会先保存一次角度。

当前实物配置：PITCH为仰角，`TREE_ANGLE_SIGN=-1.0f`，抬高激光端ELEV增大。CROSS用于观察侧倾，不阻止操作。传感器临时读取失败不阻止已经开始的激光轮次完成；会保留有效HOLD距离，但无有效同步角度时显示RANGE OK CHECK MPU，不进入高度计算。

水平距离D=L×cos(α)，树高H=D×[tan(顶角)−tan(底角)]。保留原测距200～20000mm、计算角度±80°等条件。标称22m、显示三位小数和20m树高/约0.5m误差目标，都不是本版已实测达到的指标。先用墙面两标记点、卷尺参照验证高度差。

## 接线与下载提醒

KEY1为PA0，按下高；激光PB10/TX→模块RX、PB11/RX←模块TX，沿用921600/8N1。OLED PB6/PB7，6050 PB8/PB9。底板J5为激光3.3V/GND/TX/RX接口；蓝板输出3.3V/GND经J6供激光，不能把J8的5V直接给激光。两路3.3V不并联，地共用。

不要按照片方向猜针位。拆接都先全部断电，按丝印和原针号核对。每次换版本仍须取下底板JP1、拔J5后接电脑下载；结束断电拔下载线，再恢复正常独立供电。
